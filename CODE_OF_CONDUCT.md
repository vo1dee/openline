# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion about the work. Harassment and personal attacks aren't accepted, and maintainers may remove content or block participants who don't follow this.

Report a problem privately to the maintainer through the contact on their GitHub profile.
